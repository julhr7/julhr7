# Hola, soy Julio Huamancama 👋
### Senior Full Stack Engineer & Software Architect

Ingeniero de Sistemas con más de 15 años de experiencia diseñando, construyendo y manteniendo soluciones de software de alta disponibilidad para sectores críticos (Banca, Estado, sector IT). 

Me apasiona construir arquitecturas robustas y escalables, aplicando buenas prácticas de ingeniería para resolver problemas de negocio complejos.

### 🛠️ Especialidades y Enfoque Técnico
- **Arquitectura de Software:** Diseño de sistemas basados en **Microservicios**, **Domain-Driven Design (DDD)** y patrón **CQRS**.
- **Desarrollo Backend:** Construcción de APIs y servicios de alto rendimiento, especializándome en el ecosistema **.NET 8** y **Node.js**.
- **Calidad de Código:** Aplicación estricta de principios **SOLID**, **Clean Architecture** y **TDD** (XUnit).
- **Automatización de Procesos (BPMN):** Implementación de flujos de negocio complejos utilizando **Camunda (7/8)**.
- **Cultura DevOps:** Contenerización y orquestación con **Docker**, **Podman** y **Kubernetes**, junto con pipelines de CI/CD en **Azure DevOps**.
